# StackCine Frontend

Современное клиентское веб-приложение для платформы онлайн-кинотеатра и бронирования билетов **StackCine**.

Разработано на стеке **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4** и **TanStack Query v5**, обеспечивая быстрый SSR/SSG, плавный UX и отзывчивый интерфейс.

---

## Возможности платформы

- 🎬 **Афиша и каталог фильмов**: просмотр актуальных релизов, фильтрация по жанрам и категориям, трейлеры и детальная информация.
- 🎟️ **Расписание и сеансы**: выбор кинотеатров, залов и удобного времени сеансов.
- 💺 **Интерактивная схема зала**: выбор мест в реальном времени с поддержкой бронирования и масштабирования.
- 💳 **Интеграция с платежами**: оформление заказов и безопасная оплата билетов через API Gateway.
- 👤 **Личный кабинет**: управление профилем, история заказов с динамической генерацией билетов и QR-кодов для входа в зал.

---

## Архитектура и интеграция

Фронтенд взаимодействует с бэкенд-экосистемой через **API Gateway** (`gateway-service`):
- Строго типизированные API-клиенты генерируются автоматически с помощью **Orval** на основе актуальной спецификации OpenAPI:
  ```bash
  yarn api:gen
  ```
- Для авторизации используются сессионные cookies и Bearer JWT-токены с автоматическим обновлением через интерцепторы Axios.

## Переменные окружения

Создайте файл `.env.local` в корне папки `frontend`:

```env
# Адрес API Gateway платформы
NEXT_PUBLIC_API_URL=http://localhost:4000

# URL хранилища медиа-ассетов (постеры, баннеры)
NEXT_PUBLIC_MEDIA_URL=https://63e94c8a-f620-4b81-88c9-ee90aaaa8fc8.selstorage.ru
```

## Установка и запуск

### 1. Установка зависимостей (Yarn Berry)
```bash
yarn install
```

### 2. Синхронизация API-типов
```bash
yarn api:gen
```

### 3. Запуск в режиме разработки
```bash
yarn dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000).

### 4. Продакшн-сборка
```bash
yarn build
yarn start
```
